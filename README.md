# vftypespec

fast, raw html specimen generator for variable fonts.

- official version: `/`
- workshop edition: `/laboratoriodisabotaggiotipografico/`

- drag & drop `.ttf`, `.otf`, `.woff2` with automatic `fvar` axes and `cmap` charset extraction.
- 2-color selector (background & text).
- editable name, date / year, font name, extra info, center word, and animation style.
- single-file self-contained `.html` export with embedded font.
